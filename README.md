# Marathi Biodata Builder

A responsive React + Vite application for creating Marathi matrimonial biodata with live preview, multiple templates, and PDF export.

## Features
- Multi-section form with step navigation, validation, and tooltips for Marathi-specific fields.
- Live preview that updates as you type.
- Three professionally styled templates (Traditional, Modern, Premium).
- Profile photo upload with preview.
- Export to high-quality A4 PDF.
- LocalStorage persistence for save/edit later.

## Tech Stack
- React + Vite + TypeScript
- TailwindCSS
- React Hook Form
- html2pdf.js

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Build for Production

```bash
npm run build
npm run preview
```
