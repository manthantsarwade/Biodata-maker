# Marathi Biodata Builder

A responsive web application to create, preview, and export Marathi marriage biodata profiles. The UI follows Marathi matrimonial structure with English labels, supports multiple templates, and auto-saves data locally.

## Features
- Multi-section biodata form with stepper navigation
- Live preview with three professionally styled templates
- PDF export (A4 layout, high-resolution)
- LocalStorage persistence for save/edit later
- Photo upload with instant preview

## Tech Stack
- React + Vite + TypeScript
- TailwindCSS
- React Hook Form
- html2pdf.js

## Project Structure
```
src/
  components/
  forms/
  preview/
  templates/
  utils/
```

```bash
npm install

```
